OreSim

A seed-based ore x-ray for Minecraft 26.3, 26.2 and 26.1.2 (Fabric). It works out where every ore generated from the world seed and shows it through walls, even on servers with anti-xray. Standalone, no Meteor Client needed, with optional Baritone auto-mining.

Download OreSim 1.4.0 Source on GitHub

Features

Ores from the seed

Coal, iron, gold, redstone, diamond, lapis, copper, emerald, nether quartz, nether gold and ancient debris, drawn through walls within 5 chunks.

Works behind anti-xray

The positions come from the seed, not from the blocks the server sends, so fake ores and hidden ores don't matter.

Measured accuracy

About 99% of predicted diamonds are real, 100% in the nether, tested against worlds generated by a real server.

Baritone auto-mining

/oresim mine diamond digs to the predicted ores, follows veins, picks up the drops and tunnels onward.

Remembers what's done

Mined ores and wrong predictions disappear from the overlay and are saved per server, seed and dimension.

Clean rendering

Veins drawn as one outlined shape, or boxes or outlines, with fill, line and range settings in the menu (O key).

Download and install

  1. Install Fabric Loader 0.19 or newer for your Minecraft version (Java 25+).
  2. Download the OreSim jar for your version from the latest release and put it in your mods folder, with Fabric API. Remove older OreSim jars.
  3. Optional: add the matching Baritone baritone-api-fabric jar for auto-mining.
  4. Optional, for servers whose seed you don't know: SeedCrackerX to find it.

How to use

Toggle the ore overlayX key
Choose ores and display styleO key or /oresim
Set the seed on a server/setoresimseed <seed> (remembered per server)
Auto-mine ores (Baritone)/oresim mine diamond debris, stop with /oresim stop
Show mined ores again/oresim clearmined

In singleplayer the seed is read from the world automatically. On a server you need its seed: if it isn't published, SeedCrackerX can find it (see the FAQ).

FAQ

What is OreSim?

OreSim replays vanilla ore generation from the world seed and shows where every ore is, through walls. It started as a module of the meteor-rejects addon for Meteor Client; this is a standalone Fabric mod with accuracy fixes, auto-mining and support for current Minecraft versions.

Does OreSim work on servers with anti-xray?

Yes. The positions come from the seed, not from what the server sends. With and without Paper anti-xray the accuracy differs by at most 0.4 percentage points.

Do I need Meteor Client?

No. It only needs Fabric API, and it works alongside Meteor Client if you use it.

Where do I get the seed of a server?

A server never sends its seed, but some servers publish it. Otherwise SeedCrackerX, a separate Fabric mod not affiliated with OreSim, can work it out while you explore: it records structures you pass (shipwrecks, desert pyramids, igloos, swamp huts, outposts) and cracks the seed from them, usually in a few minutes. Download it only from its GitHub releases or official CurseForge page. Then set the seed with /setoresimseed. In singleplayer OreSim reads the seed automatically.

Why is a predicted ore sometimes wrong?

Tunnels dug by other players, chunks generated by older Minecraft versions, or world-generation datapacks change what generated. Predictions that turn out wrong once you can see the block are hidden automatically.

Using x-ray or automated mining on a server you don't run may break its rules and get you banned. Check first.
